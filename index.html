📋 4 ขั้นตอนง่ายๆ ในการเชื่อมต่อฐานข้อมูล:

  1. ไปที่ Firebase Console แล้วกด "Add project"
  2. เข้าเมนู Authentication > แถบ Sign-in method > กดเปิดใช้งาน Email/Password
  3. เข้าเมนู Firestore Database > กด Create database (เลือก Start in test mode)
  4. กดรูปเฟือง ⚙️ Project settings > เลื่อนลงมาที่ Your apps > เลือกเว็บ </> แล้วคัดลอกโค้ด firebaseConfig มาวางด้านล่างนี้
